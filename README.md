# Qwixx Score

A digital score sheet for the Qwixx dice game, for phones. Each player uses it on their own phone instead of a paper sheet. Works offline once installed.

Open https://sgoodwin-cloud.github.io/qwixx-score/ in Safari, tap Share, then Add to Home Screen. Turn the phone sideways to play.

Qwixx is a game by Steffen Benndorf, published by Nürnberger-Spielkarten-Verlag. This is an unofficial fan-made score sheet. Font: Barlow Semi Condensed (SIL Open Font Licence).
